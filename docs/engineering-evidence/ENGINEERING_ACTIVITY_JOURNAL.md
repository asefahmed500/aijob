## E-003 — NestJS backend foundation

- **Original request (user, inherited from planning):** "use nestjs as backend"; build the complete email → evidence → cover letter → export workflow first.
- **Requirement:** REST API, persistence, auth, ownership checks, AI integration, exports.
- **Investigation (agent):** resolved current docs for NestJS 12 and Prisma 7 via Context7. Prisma 7 no longer accepts `url` in `schema.prisma`; it requires `prisma.config.ts` and a driver adapter.
- **Architecture decisions (agent, under user instruction):** two-service split (Next.js at root, NestJS in `server/`); Prisma ORM; JWT auth in NestJS instead of Better Auth; backend-only AI calls. Recorded in `DATABASE_AND_API_DECISIONS.md`.
- **Files created (agent):** `server/package.json`, `tsconfig.json`, `nest-cli.json`, `prisma.config.ts`, `prisma/schema.prisma`, `src/main.ts`, `src/app.module.ts`, `src/prisma/*`, `src/common/*`, `src/jwt.strategy.ts`, and modules `auth`, `applications`, `emails`, `evidence`, `letter`, `ai`, `exports`.
- **Database design (agent):** `User`, `Application`, `EmailSource`, `Evidence`, `CoverLetter`, `LetterClaim`, `ExportLog` with cascade deletes and indexes on owner and parent ids.
- **API changes:** 15 REST endpoints recorded in `DATABASE_AND_API_DECISIONS.md`.
- **Validation/auth:** DTOs with `class-validator`; global `ValidationPipe({ whitelist: true, forbidNonWhitelisted: true })`; `JwtAuthGuard` on all application-scoped routes; every service checks `findOwned(userId, id)`.
- **Errors fixed (agent):** missing `PrismaModule` imports in five modules; missing `AiModule` imports in evidence and letter modules; `cookie-parser` namespace import; build output at `dist/src/main.js` instead of `dist/main.js`; generated Prisma client had to be copied into `dist/generated` for runtime.
- **Committed:** `c663b64` — "feat: NestJS backend with JWT auth, evidence trust boundary and five export channels".

## E-005 — Z.ai key failure and deterministic fallback

- **Reported behavior:** direct call to `https://api.z.ai/api/paas/v4/chat/completions` with configured key returned HTTP 429, code `1113`, message "Insufficient balance or no resource package. Please recharge."
- **Impact:** AI extraction and generation could not be verified with the provided key.
- **Decision (agent):** add an explicit, labelled fallback rather than fabricate AI results. Added `source` field to `Evidence` and `CoverLetter`; `deterministicEvidence` selects exact lines from email bodies; `deterministicLetter` maps each factual sentence to an evidence id; both fallbacks still pass through the quote/claim validators.
- **Files:** `server/src/ai/deterministic.ts`, `server/src/ai/zai.client.ts`, `server/src/evidence/evidence.service.ts`, `server/src/letter/letter.service.ts`, `server/prisma/schema.prisma`.
- **Verification:** end-to-end run reported `usedFallback: true`, `evidenceSource: "deterministic"`, `letterSource: "deterministic"`.
